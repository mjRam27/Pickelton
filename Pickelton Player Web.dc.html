Pickelton for web
The same player experience as mobile, re-laid-out for the desktop web: a persistent labeled left rail instead of a bottom bar, a utility top bar with global search + create, and multi-column dashboards that use the extra width — split map/list for Courts, a two-pane match browser, side-by-side live scoreboard. Brand DNA is identical (Space Grotesk numerals, forest green + lime), just breathing at 1440.
